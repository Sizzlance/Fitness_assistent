# Fitness Assistant (MediaPipe & OpenCV)

Прототип фитнес-ассистента для анализа физической активности в режиме реального времени.

## Описание
Проект использует компьютерное зрение для отслеживания ключевых точек тела и анализа правильности выполнения упражнений. 

## Основной функционал:
* Анализ тела человека через MediaPipe.
* Оценка состояния тела (ИМТ, Процент подкожного жира, осанка, тип фигуры)
* Визуализация скелета и ключевых точек.
* Планировщик тренировок на основе полученных данных.

## Стек технологий
* **Python 3.x**
* **OpenCV** — обработка видеопотока.
* **MediaPipe** — распознавание поз (Pose Estimation).
* **Streamlit** — графическая оболочка.
